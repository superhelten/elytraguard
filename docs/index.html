For WARDOGS players on Windows

Elytra runs while you play. Not after.

WARDOGS starts the Elytra anti-cheat as a Windows service with full system rights. It can keep running after you close the game. ElytraGuard stops it once the game is gone. It is free, open source and plain PowerShell you can read before you run it.

  • Never acts while the game runs
  • No network, no telemetry

Why

In September 2026 WARDOGS replaced Easy Anti-Cheat with Elytra, made by VAIIYA. It installs a Windows service, Elytra.Service, that runs as LocalSystem, the most privileged account on your PC. The game starts the service when it launches, and it can keep running after you quit.

Anti-cheat during a match is part of the deal. Anti-cheat running with full system rights while you browse, work or bank is not. ElytraGuard makes sure Elytra only runs while you play.

How it works

A scheduled task runs elytraguard.ps1 as SYSTEM at startup and every 5 minutes. On each run it checks the following, in order:

  1. Is Elytra running?

    If it isn't, nothing to do.

  2. Is the game running?

    If any process from the WARDOGS install folder is running, Elytra is left alone. ElytraGuard finds that folder through your Steam libraries, so this still works if a game update renames its executables. The check then waits for the game to close and carries on about a minute after you quit, instead of at the next run.

  3. Did Elytra just start?

    If the service started less than 10 minutes ago, it is left alone, so a game that is still loading is never cut off. After waiting for the game to close, this check is skipped.

  4. Otherwise, stop it.

    It uses the standard Windows service stop, the same thing the Services app does. The next time you launch WARDOGS, the game starts Elytra again as usual.

Every run writes one line to C:\ProgramData\ElytraGuard\elytraguard.log, and one every 5 minutes while it waits for the game, so you can always see what it did and why.

Install

You need Windows 10 or 11 and an administrator account. There is nothing else to install: it uses the PowerShell that ships with Windows.

With the setup program

Download elytraguard-setup.exe, run it and accept the admin prompt. The setup program isn't code-signed, so SmartScreen may say Windows protected your PC: choose More info, then Run anyway. Its hash is in SHA256SUMS.txt on the release page. Setup only unpacks the scripts and runs the same install.ps1 as the steps below, and adds ElytraGuard to Settings > Apps > Installed apps so you can uninstall it there. Then check that it works, as in step 3.

Or from the zip

  1. Step 1

    Download and unzip

    Download elytraguard.zip and extract it, for example to your Downloads folder. To check that the download wasn't tampered with, compare its hash with SHA256SUMS.txt on the release page:

    PowerShell
    Get-FileHash "$HOME\Downloads\elytraguard.zip" -Algorithm SHA256
  2. Step 2

    Run the installer

    Open Terminal (right-click Start) and run the commands below. The installer asks for administrator rights and carries on in a new window. If you have downloaded ElytraGuard before, Windows may have named the new folder elytraguard (1); change the first line to match.

    PowerShell
    cd "$HOME\Downloads\elytraguard"
powershell -ExecutionPolicy Bypass -File .\install.ps1

    This copies ElytraGuard to C:\Program Files\ElytraGuard, where normal programs can't change it, and registers the ElytraGuard scheduled task.

  3. Step 3

    Check that it works

    PowerShell
    & "$env:ProgramFiles\ElytraGuard\status.ps1"

    It starts with OK or NOT OK and what is wrong, says whether Elytra is running right now, and lists what the guard did recently. The real test is your next match: while you play it shows WARDOGS open, Elytra left running, and about a minute after you quit, WARDOGS closed, Elytra stopped by ElytraGuard.

Reading the log

Each run logs a result:

resultmeaning
idleElytra not running, nothing to do
game_runningYou're playing, Elytra left alone
graceElytra started recently, left alone for now
stoppedElytra was stopped
would_stopDry run, nothing was stopped
no_serviceElytra isn't installed
acceptedAn admin accepted Elytra's current setup
errorSomething failed; the line says what

Running a log stack such as Loki and Grafana? The README has three ready-made alert rules. They tell you if the guard stops running, if Elytra keeps running without the game, or if the guard reports an error.

Uninstall

If you used the setup program, uninstall ElytraGuard from Settings > Apps > Installed apps. It asks whether to delete the log and the record of Elytra's setup too. Otherwise, run this from the unzipped folder; like the installer, it asks for administrator rights. This removes the task and the program folder, and with -RemoveLogs also the log and the record of Elytra's setup. Elytra and WARDOGS are not touched.

PowerShell
powershell -ExecutionPolicy Bypass -File .\uninstall.ps1 -RemoveLogs

FAQ

Can this get me banned?

ElytraGuard never acts while the game is running. It only stops the service after you have quit, and the game starts the service again on the next launch. It doesn't modify, block or hide from Elytra. That said, it is not affiliated with or approved by the game's makers, so there is no guarantee. Read the game's terms, and use it at your own risk.

Does it touch game or anti-cheat files?

It never changes them. It reads the Steam library index to find the game folder, lists running processes, and reads Elytra's service settings and program files to notice when an update changes them. The only thing it changes about Elytra is whether Elytra.Service is running.

Why does it need administrator rights?

The scheduled task runs as SYSTEM, and setting one up takes an administrator. Running as SYSTEM lets it see which programs run from the game folder, and keep its log and its record of Elytra's setup where normal programs can't change them. That is also why the script is installed where normal programs can't edit it.

Does it send any data anywhere?

No. ElytraGuard itself makes no network connections. When Elytra's program files change, it asks Windows to verify their code signature, and Windows may then download a missing certificate the same way it does for any signed program. The log and the record of Elytra's setup stay on your PC. This page has no analytics, cookies or trackers either.

What if WARDOGS or Elytra updates?

The game is detected by its install folder, not only by process names, and Elytra by its service or program path. If the game folder can't be found, the guard falls back to known process names and logs a warning. status.ps1 then shows NOT OK.

ElytraGuard also records how Elytra is set up: its service settings, its program files and who signed them, and any other service, driver or scheduled task it adds. An ordinary update, validly signed with a certificate it has seen before (matched by thumbprint, not by name), is simply noted. A new driver, an unsigned file, a service that starts with Windows or runs as another account is a warning until you accept it with elytraguard.ps1 -AcceptElytraChanges, which asks for administrator rights.

Is Elytra kernel-level?

Public reports disagree, and the game's privacy policy doesn't name Elytra. ElytraGuard stops the Windows service that Elytra installs. It does not inspect or unload drivers.

Linux or Steam Deck?

No. ElytraGuard is Windows only, because the service it manages is a Windows service.

Read before you run. ElytraGuard is one PowerShell script of about 500 lines, plus an installer and a status check. Anything that runs with administrator rights should be something you can inspect. The full source, history and issues are on GitHub.
